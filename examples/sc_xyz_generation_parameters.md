## 1. sc_W3_ALocal.xyz

### Proven historical provenance

This file was generated by **Generate SC V2.2**, before arm-phase trimming and qualifying-view screening were introduced. An archived V2.2 regeneration is byte-for-byte identical to the file.

Recovered parameters:

- Closed contour length: `1071`
- Signed writhe: `+3`
- Opening-angle objective: `max-local` (minimize the largest local curvature)
- Arm-phase trimming: unavailable in V2.2, therefore untrimmed (`phase_trim = 0`)
- Arm phase: `+3*pi`
- Output points: `2000`
- Decimal precision: `8`
- Automatically selected opening angle: `49.0625 deg`
- Serialized-coordinate writhe: `3.000161279739`
- SHA-256: `035f4fc7b78e11a3d88fe524db824812a7bc9ef3e85e46db4fc5fcbcff6ca259`

Historical command that exactly generated the file:

```bash
python3 curve_it_lib/generate_sc_xyzV2_2.py \
  -L 1071 -w 3 \
  --angle-objective max-local \
  -n 2000 --precision 8 \
  -o sc_W3_ALocal.xyz
```

### Recommended V3.5 equivalent

Use `--no-trim` explicitly. Without it, V3.5 applies its modern trimming/screening geometry and produces a substantially different curve.

```bash
python3 curve_it_lib/generate_sc_xyzV3_5.py \
  -L 1071 -w 3 \
  --angle-objective max-local \
  --no-trim \
  -n 2000 --precision 8 \
  -o sc_W3_ALocal_V3_5.xyz
```

V3.5 selects the same `49.0625 deg` opening angle. Its output is very close to the historical curve (`0.029818502 A` coordinate RMS difference; `0.042216687 A` maximum point difference), but not byte-identical because V3.5 applies a newer final exact-polyline writhe refinement. Its achieved writhe is `3.000004970`. Keep the existing V2.2 XYZ file when exact historical coordinates are required.

`--qualifying-views` and `--minimum-final-radius` should not be supplied for this historical-equivalent geometry. With `--no-trim`, V3.5 reports multi-view statistics diagnostically but does not use them to change the curve.

- SHA-256: `0bed9ea91d97c6457f2bce5ecef04d333f0ef2224c6746f0384610d6970372ee`

Current V3.5 command that exactly reproduces the file:

```bash
python3 curve_it_lib/generate_sc_xyzV3_5.py \
  -L 1071 -w 3 \
  --angle-objective bending-energy \
  --trim \
  --minimum-final-radius 11 \
```

The `--minimum-final-radius 11` argument is essential because the current V3.5 package default is radius `13`. The other explicit arguments are included to make the command reproducible even if future defaults change.
